FAQ

How does this site work without JavaScript?

It relies entirely on semantic HTML5 structures and modern CSS grid properties to handle responsive layouts and native user interactions natively in-browser.

Where is this website hosted?

This site is hosted as an isolated Tor hidden service. It consists entirely of flat, static files with no dynamic backend.

What do the essays cover?

The essays cover static web architecture, Tor hidden service design, operational security, the case against JavaScript, and the culture of encrypted communication. They are short, technical, and opinionated. The full list is on the essays page.

How often are new essays published?

There is no fixed schedule. Essays are published when there is something worth saying. Quality over frequency is the operating principle here.

How do I verify the PGP key is genuine?

The public key is embedded directly in this page rather than hosted on a keyserver. Cross-reference the fingerprint against any other channel you have independently verified — such as a signed message from this address. The fingerprint for the current key is 45F5 5D29 3FBE 4350 E808 A2D9 2473 87A3 6F80 BEE7.

Does this site track visitors?

No. There are no analytics, no cookies, no logging of visitor data, and no third-party resources loaded from anywhere. The server returns files. That is all it does.
